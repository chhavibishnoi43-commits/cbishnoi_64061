Advanced Machine Learning¶

I will compare different model structures and settings instead of depending on a single configuration. My goal is to see which changes improve validation performance and which ones do not make a meaningful difference.

# Convert each movie review into a binary vector

def encode_movie_reviews(review_collection, vocabulary_size=10000):
    encoded_reviews = np.zeros((len(review_collection), vocabulary_size))

    for review_number, word_numbers in enumerate(review_collection):
        encoded_reviews[review_number, word_numbers] = 1.0

    return encoded_reviews


# Encode both training and testing reviews
train_features = encode_movie_reviews(review_train, word_limit)
test_features = encode_movie_reviews(review_test, word_limit)

# Convert labels into decimal values for the neural network
train_targets = np.asarray(label_train).astype("float32")
test_targets = np.asarray(label_test).astype("float32")

print("Training data shape:", train_features.shape)
print("Testing data shape:", test_features.shape)

Experiment 1: One Hidden Layer¶

I started by testing a simpler neural network with only one hidden layer. I wanted to see whether reducing the depth of the network would still allow it to recognize the difference between positive and negative movie reviews. This also gives me a starting point that I can compare with deeper models later.

In [105]:
# Experiment 1: Neural network with one hidden layer

    layers.Input(shape=(10000,)),
    layers.Dense(16, activation="relu"),

one_layer_net.compile(

Final Conclusion¶

Working through these experiments showed me that making a neural network larger or more complicated does not automatically make it perform better. My one-hidden-layer model reached 88.18% validation accuracy, while the three-hidden-layer model reached 88.45%. However, the test results showed a different pattern. The one-hidden-layer model achieved 87.14% test accuracy, compared with 86.18% for the three-hidden-layer model. This helped me see that a small improvement in validation accuracy does not always lead to better performance on unseen data.

Increasing the number of hidden units was more useful in my experiments. The 32-unit model reached 88.61% validation accuracy, while the 64-unit model reached 88.71%. Changing other parts of the network also produced similar results. Using MSE gave a best validation accuracy of 88.71%, the tanh model reached 88.28%, and the dropout model reached 88.70%. Since these results were very close, no single change produced a dramatic improvement.

Another pattern I noticed was that training accuracy continued to increase even when validation accuracy stopped improving. This made overfitting easier for me to recognize and showed me why training accuracy alone does not give the full picture of how well a model is performing.

For the final evaluation, I used the 64-unit architecture, which was one of the strongest configurations during validation. The final model achieved 87.92% accuracy on the untouched test data, with a test loss of 0.3085. Overall, these experiments helped me understand that neural network tuning is not simply about adding more layers or units. It is about comparing different settings and finding a balance between learning the training data and performing well on data the model has not seen before.
